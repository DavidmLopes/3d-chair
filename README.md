# 3D Office Chair

An interactive Three.js chair viewer with four materials and orbit controls.

## Getting started

Use Node.js 24 and npm.

```sh
nvm use
npm ci
npm run dev
```

Press **d** to toggle the settings panel.

## Commands

```sh
npm run build         # Build to dist/
npm run preview       # Preview the production build
npm run format        # Format the code
npm run format:check  # Check formatting
```
